# Origin Design Studio

A modern design agency website built with Next.js and Tailwind CSS.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Setup Instructions

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build Project

```bash
npm run build
```

## Features

- Responsive Design
- Hero Section
- Services Section
- Portfolio Section
- Contact Section

## Assumptions

- Portfolio projects are sample projects.
- Contact form is frontend only.

## Additional Features

- Mobile Responsive
- Smooth Animations
- Modern UI Design
